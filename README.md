# CrickLiveTv 🏏📺

CrickLiveTv is a professional Android application designed for cricket enthusiasts. It features a modern user interface, a beautiful splash screen, and personalized customization options.

## ✨ Features

- **Beautiful Splash Screen**: A professional indigo-themed launch screen to welcome users.
- **Customization Options**:
    - **Set Ringtone**: Automatically sets a custom cricket-themed ringtone to your device.
    - **Set Wallpaper**: One-click option to set a high-quality cricket-themed background.
- **User Friendly UI**: Clean, modern, and easy-to-navigate design.
- **AndroidX & Jetifier**: Fully migrated to modern Android standards for better stability and performance.

## 🛠️ Technical Stack

- **Language**: Java
- **UI Framework**: Android XML (Material Design)
- **Minimum SDK**: 21 (Android 5.0)
- **Target SDK**: 34 (Android 14)
- **Architecture**: Standard Android (Migrated from legacy decompiler structure)

## 🚀 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Abhimanyukumar-lab/cricklivetv.git
   ```
2. Open the project in **Android Studio**.
3. Sync the project with Gradle files.
4. Run the app on an emulator or a physical device.
